Put your own stock or AI generated test photos here, named after the demo users
in demo_data.php (lowercase first name): jake.jpg, jake-2.jpg, sarah.png, ...
Up to 4 per person. The first one becomes their main photo.
Then run install/install.php with &remove_demo=1&demo=1 to rebuild the demo users.
Anyone without a file here gets a free stock portrait from randomuser.me.
